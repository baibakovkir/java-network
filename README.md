# Клиент-серверное приложение

Сервер принимает подключения на порту 8080. Клиент подключается по адресу
`netology.homework` и ведёт диалог в рамках одного соединения: вводит имя,
отвечает на вопрос о возрасте и получает приветствие. Пустое имя и ответ,
отличный от `yes`/`no`, вызывают повторный вопрос. Регистр ответа не важен.
Сервер выводит имя и порт клиента и после диалога ждёт следующее подключение.

## Настройка и запуск

1. Добавьте в системный файл `hosts` строку:
   ```text
   127.0.0.1 netology.homework
   ```
   В Windows файл расположен в `C:\Windows\System32\drivers\etc\hosts`
   (редактор нужно открыть от имени администратора), в Linux/WSL — `/etc/hosts`.
   Меняйте файл в той системе, где запускаете Java. Сам файл в репозиторий не входит.
2. Откройте проект как Gradle-проект в IDE.
3. Запустите `ru.netology.Server`, затем, оставив сервер работать,
   запустите `ru.netology.Client`.
4. Вводите ответы в консоли клиента. Для остановки сервера завершите его процесс.

## Пример диалога

```text
Write your name
Kirill
Are you child? (yes/no)
no
Welcome to the adult zone, Kirill! Have a good rest, or a good working day!
```
